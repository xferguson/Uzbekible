# Imlo balance (I8)

Scoring parameters live in `src/games/imlo/scoring.config.ts`; this page justifies them with the simulator.

## How it was run
`npm run sim -- --game imlo --levels 1-60 --profiles novice,b1-turkish,expert --runs 300 --seed 1`
(`imlo` = Oson, `imlo-orta`, `imlo-qiyin`).

The sim drives the real I3 rules through `toSimGame` with a harness (`src/games/imlo/balance.ts`). Pair content is a
synthetic stand-in for I2's generator: word lengths, pair counts and bank sizes follow `difficulty.config.ts`, the
letters are placeholders. The shipped game never imports the harness.

**Player model.** A step is one tile tap, so the Imlo profiles (`IMLO_PROFILES`) are per-tap, not Juft's per-decision:

| Profile | Tap median | Spread | Scan per tile left in the bank | Hard-letter accuracy (transparency 0 / 1) |
|---|---:|---:|---:|---|
| novice | 1400 ms | 0.35 | 90 ms | 0.40 / 0.90 |
| b1-turkish | 900 ms | 0.30 | 55 ms | 0.60 / 0.97 |
| expert | 550 ms | 0.25 | 25 ms | 0.85 / 0.995 |

Only the tap that decides a **hard letter** can go wrong: a letter where the Uzbek spelling departs from the source
word (isim ↔ ism, k ↔ q). Hard letters per word grow with the chapter (1, 2, 3, 4). Every other tap is a free,
always-right tap that still costs time. A hard letter's transparency falls with the level (0.97 at level 1, 0.80 at
level 60, linear between anchors) and **loses 0.02 per distractor in the bank** (Qiyin only: 2 to 4), which is the
"error rate rising with distractors". A wrong tap puts a tempting tile in (the source-side counterpart if it is
still in the bank, else a distractor, else any other letter). After a wrong check the bot takes the wrong slots out
and decides them again.

**What the model shows about the modes.** With an exact bank (Oson, Oʻrta) a wrong early tap leaves the wrong tile
over for a later slot, so the bot notices and fixes it *before* checking: wrong checks are rare, and both modes
play alike. Distractors break that tell, which is why Qiyin's failures come from wrong checks. **Not modelled:**
Oson's source/Uzbek tile colours (so Oson and Oʻrta have one table below), reading Cyrillic, hints, and the
pair-by-pair rise in difficulty from real content. Recalibrate when I2's real content and play data exist.

## Parameters
| Knob | Value |
|---|---|
| Par per level | 1.0 s + sum over pairs of (1.2 s + letters x (520 ms + 38 ms x bank size)); `letters` = source + Uzbek, `bank` includes distractors; level 60 is 5% tighter than level 1, linear between |
| Base points / overrun | 1000 / time points reach 0 at 3x par |
| Wrong check / hint penalty | 100 (and one life) / 150 |
| Combo bonus | 10 per first-try pair |
| Stars | 1 / 2 / 3 at 250 / 600 / 900 points (after multipliers) |
| Mode multiplier | Oson x1, Oʻrta x1.25, Qiyin x1.5 (`ScoreInput.multipliers`) |
| Cyrillic multiplier | x1.2 (a second entry in `multipliers`) |

Par is built from what the player does, so a long word, a big bank or a Qiyin distractor all lengthen it. It is
set so a B1 player finishes in about 1.3-1.5x par (time points 75-85%: two stars, three with first-try pairs and a
mode multiplier), the expert in about 0.8x par (three stars) and the novice in about 2.1-2.5x par (one star).
The simulator applies no `multipliers`, so the harness folds the mode multiplier into the scoring config; thresholds
are the same in every mode, so a harder mode earns its stars from the same play; the multiplier is the reward for the extra risk.

## Results (seed 1, 300 runs)
| Target | Result |
|---|---|
| Flawless at par = 3 stars in every mode | Property test over random levels, modes, scripts |
| Novice earns >= 1 star on levels 1-5 | Oson: 99-100% of runs; Qiyin: 83-89% (the rest are fails or 0-star clears) |
| Expert reaches 3 stars | Oson 100% on every level; Qiyin 95-100% completion, all clears 3 stars |
| B1 on Oson | 100% completion on all 60 levels; 2 stars on most levels, 3 stars on the shortest boards (no wrong checks, so the stars are the time) |
| Qiyin clearly harder (B1) | Completion 100% (level 1-15), 95-97% (16-30), 77% (31), 66% (45), 51% (46), 39% (60); Oson completes 100% throughout |

Failure past level 30 in Qiyin is meant to bite (the expert stays above 95%); the B1 numbers at 46-60 are the ones
to revisit once real content and play data exist.
