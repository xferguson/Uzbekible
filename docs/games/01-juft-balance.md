# Juft balance (E3)

Scoring parameters live in `src/games/juft/scoring.config.ts`; this page justifies them with the simulator.

## How it was run
`npm run sim -- --game juft --levels 1-120 --profiles novice,b1-turkish,expert --runs 500 --seed 1`

The sim drives the real E2 rules through `toSimGame` with a harness definition (`src/games/juft/balance.ts`).
The bot taps a left tile (free), then decides the right tile (the only tap that can be wrong). Scan time is modelled
per tile still on screen (`scanMsPerChoice` x remaining tiles), so 10-12 pair boards cost visibly more per pair.
**Assumptions to recalibrate when E1 and real play exist:** pairs per level follow the chapter table in
`01-juft.md` (every 5th level is a one-pair hard pair); "transparency" (the share of the board a player recognises)
is an anchor curve, 0.95 at level 1, 0.6 at level 10, 0.4 at level 30, rising to 0.7 by level 120. Pair counts and
transparency are stand-ins for E1's generator and content, not shipped code.

## Parameters
| Knob | Value |
|---|---|
| Par per level | 1.5 s + pairs x (base + 225 ms x (pairs + 1)); base 4.0 s at level 1 falling linearly to 2.8 s at level 120 |
| Base points / overrun | 1000 / time points reach 0 at 3x par |
| Mistake / hint penalty | 80 / 150 |
| Combo bonus | 10 per correct match |
| Stars | 1 / 2 / 3 at 250 / 600 / 900 points |
| Cyrillic multiplier | x1.2 (applied through `ScoreInput.multipliers`) |

Par is quadratic in pair count because each tap pays a search over the tiles left; it is set at about 75% of the
`b1-turkish` time, so a B1 player lands on 2-3 stars and the expert on 3.

## Results (seed 1, 500 runs)
| Target | Result |
|---|---|
| Novice clears levels 1-5 with >= 1 star | 100% completion; 87-99% of runs earn a star (level 4, the first 2-pair board, is the low point at 87%) |
| b1-turkish failure 10-25% on levels 10-30 | 3-32% per level on non-breather levels, mean 14.9% (one-pair hard-pair levels cannot fail) |
| Expert | Levels 10-30 fail 1.6% on average; 12-pair boards fail 5-7% (the lives bound, not speed) |
| Late game | 12-pair levels (106-119): b1-turkish fails about 40%, expert 5-7%. b1 3-star share falls from 86% (level 1) as boards grow and par tightens; the tables below have every level |

Failure past level 30 is not targeted by the task; the ~40% on Registon boards is the number to revisit once E1
supplies real content and play data exists.
