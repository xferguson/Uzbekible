## `core/random`

- `Rng` { next(): number; int(min: number, max: number): number } - Deterministic randomness: mulberry32 PRNG plus helpers. Never use Math.random in games or tests.
- `createRng(seed: number): Rng`
- `sample<T>(rng: Rng, items: readonly T[], n: number): T[]` - Up to `n` distinct elements (by position), in random order.
- `seedFrom(text: string): number` - FNV-1a 32-bit hash of a string, for turning text (e.g. a daily key) into a seed.
- `shuffle<T>(rng: Rng, items: readonly T[]): T[]` - Fisher–Yates; returns a new array and leaves the input untouched.
- `weightedPick<T>(rng: Rng, items: readonly T[], weights: readonly number[]): T` - Index-aligned weights; returns the chosen item. Zero-weight items are never picked.
