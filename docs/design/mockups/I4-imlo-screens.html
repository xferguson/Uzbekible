Oson · the easy-mode colouring

Colour is a hint, never a rule

Letters from the source word are tinted turquoise and carry a ◆ in the corner; letters from the Uzbek word are tinted cobalt, have a double edge and carry a ●. Take away the colour and the shapes still say which word a tile came from. Correctness is by letter value, so a ◆ tile in an Uzbek slot is fine (the second slot below holds one, and the word is right).

Six scripts

The same board in every script

Turkish and Russian run left to right; Persian and Arabic slot rows run right to left, with the first letter at the right. In every language the word is built from separate isolated-form tiles, and no joined preview of the word is ever shown (decision 2 in the game spec). Uzbek oʻ, gʻ, sh, ch are single tiles, so Latin and Cyrillic boards have the same tile count.

Motion

Place, glaze, crack, hint

The same timings and easing as Juft, held in the shared constants. Each animation has a reduced-motion replacement that keeps the shape cue and drops the movement.

Fit

Slot and tile sizes

The board never scrolls. Slot size steps down with the word length so 8 letters fit at 390 px wide; the bank wraps to as many rows as it needs. All sizes are at or above 44 px.

Contrast

New colour pairs

One new token, --color-cobalt-pale, tints the Uzbek letters in Oson. Every pair that touches it passes; the pairs are in contrast.mjs and the numbers below are computed from the same formula.
